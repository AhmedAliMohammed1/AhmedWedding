# دعوة زفاف احمد والاء

دعوة عربية من اليمين إلى اليسار، لموعد الخميس ٢٢ أكتوبر ٢٠٢٦، الساعة ٩ مساءً بتوقيت القاهرة، في قاعه فيلا باريس.

- العنوان المثبت في خرائط Google: طريق البحر ههيا – الزقازيق، محافظة الشرقية، مصر.
- صور الزوجين وشعار المكان مقدمة من صاحب المشروع. لم تتوفر صور موثقة لعمارة القاعة.
- لوحة عاجية ووردية وزرقاء، خط Amiri محلي، تصميم متجاوب وحركة مخففة حسب تفضيل الجهاز.
- عدّ تنازلي، موسيقى باختيار الزائر، تكبير الصور مع تنقل وإغلاق بمفتاح Escape، وخريطة واتجاهات.
- سجل تهانٍ بالاسم أو دون اسم؛ لا يوجد نموذج RSVP في المشروع الأصلي.
- فصل تخزين التهاني باستخدام `ahmed-alaa-2026-guest-notes` لمنع خلطها برسائل الدعوة السابقة.

## التشغيل

`npm ci` ثم `npm run dev`.

`npm run build` للبناء، و`npm test` للاختبارات.

البيانات في `src/config/invitation.ts`. موعد الانتهاء غير معروف ولم يُفترض. عنوان النشر غير معروف، لذا لا يوجد رابط canonical وهمي. اضبط `social.siteUrl` عند اعتماد نطاق النشر، وأضف sitemap للنطاق الفعلي.

خدمة التهاني تعتمد على وظائف Netlify أو Vercel وتخزينهما الموجود في المشروع. المعاينة الثابتة وحدها لا تحفظ التهاني؛ يلزم تشغيل التكامل المحلي أو النشر الكامل. لا تتغير أي بيانات مخزنة للدعوة السابقة.
